# AgroEvolution
 
AgroEvolution is the farming and agribusiness venture of Technophiles Conglomerate Africa. It is built around the value chains where African producers can add value locally and reach larger markets.
 
## Focus
 
* Value addition and processing for farm produce
* Reliable supply chains from producer to buyer
* Practical tools for aggregation, quality and logistics
 
## Status
 
Pre launch. A demo is available.
